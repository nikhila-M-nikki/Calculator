# 🧮 Python Calculator

## About the Project
This is a simple calculator application developed using Python. It performs basic arithmetic operations with a simple and user-friendly interface.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## Technologies Used
- Python

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/nikhila-M-nikki/Calculator.git
   ```

2. Open the project folder.

3. Run the Python file:
   ```bash
   python calculator.py
   ```
